BUAT UNDANGAN CUSTOMER BARU

Pilih tema, isi detail acara, lalu klik Buat Undangan. Form kini berbentuk langkah yang bisa dilipat — wajib diisi hanya 1–4; bagian lain (foto, amplop, love story, musik, dsb.) opsional dan tinggal dibuka saat perlu. Sistem akan menyalin tema, mengganti seluruh data demo dengan data customer, menautkan RSVP pusat otomatis (tanpa isi URL per customer), dan mencatatnya ke daftar customer dalam satu commit.

PENYIMPANAN LANGSUNG (GITHUB)

Agar tombol simpan langsung mengubah repo dari browser, buat GitHub Personal Access Token (fine-grained): buka github.com → Settings → Developer settings → Fine-grained tokens → Generate. Beri akses Contents: Read and write hanya untuk repo bernaunginv. Token disimpan hanya di browser Anda (localStorage) dan tidak pernah dikirim ke tempat lain.

Kolom pengaturan terkunci agar tidak berubah saat salah pencet. Klik UBAH PENGATURAN untuk membuka, lalu SIMPAN PENGATURAN untuk menyimpan sekaligus mengunci kembali.

Tanpa token: panel tetap bisa dipakai — hasil perubahan/undangan akan diunduh sebagai file untuk Anda unggah manual ke GitHub (Add file → Upload files).

GANTI PIN ADMIN

PIN saat ini tersimpan sebagai hash di assets.bernaung.id/admin-auth.js. Dengan token terpasang, panel bisa menggantinya otomatis. Tanpa token, unduh file baru lalu unggah manual menggantikan file lama.

RSVP PUSAT (SATU SPREADSHEET UNTUK SEMUA CUSTOMER)

Sekarang tidak perlu setup Google per customer. Cukup satu Spreadsheet + satu Apps Script untuk semua undangan: RSVP tiap customer otomatis masuk ke tab terpisah bernama slug customer (mis. nasirin-mila), dibuat otomatis saat RSVP pertama masuk.

1. Buat Spreadsheet baru di sheets.google.com → Extensions → Apps Script.
2. Hapus kode bawaan, tempel isi file assets.bernaung.id/Code.gs (versi pusat, tersedia juga di panel ini), Save.
3. Deploy → New deployment → Web app → Execute as: Me, Who has access: Anyone → Deploy → Allow.
4. Salin URL berakhiran /exec → tempel di kolom URL Apps Script di bawah, dan tempel juga alamat spreadsheetnya di kolom Link Google Spreadsheet.
5. Simpan Pengaturan → URL ini otomatis dipakai semua customer (baru maupun saat diedit ulang) — tidak perlu mengisi lagi di form Customer Baru.
6. Selesai — RSVP semua customer terkumpul di satu spreadsheet, terpisah per tab customer.

Data RSVP lama yang masuk tanpa slug tetap terkumpul di tab RSVP. Deploy ulang akan terjadi otomatis di tab-tab berikutnya jika URL di atas berubah.

EDIT MAPPING —

Panel ini membaca file <tema>/index.html, mendeteksi frasa demo & path foto, lalu memetakan ke field form admin. Hasil tersimpan ke assets.bernaung.id/theme-map.json. Tidak menyentuh file tema apa pun.

TEKS DEMO → FIELD

Setiap baris = frasa demo yang terdeteksi di HTML tema. Pilih field form yang akan menggantikan frasa itu saat generate customer. Prefix opsional (mis. "Pukul " untuk jam).

FOTO DEMO → SLOT

Path foto demo di HTML tema. Pilih slot (fotoCover/fotoGroom/fotoBride/fotoGalleryN) supaya upload foto customer otomatis menggantinya saat generate.

BAGIAN OPSIONAL → HIDE RULE

Frasa seperti “Amplop Digital”/“Love Story” terdeteksi otomatis. Centang → bagian disembunyikan saat field terkait kosong. Field usulan sudah diisi, bisa diubah di theme-map.json setelahnya.

MODE MANUAL — UNGGAH FILE INI KE GITHUB

Token GitHub belum terpasang, jadi berikut file hasil proses. Klik unduh lalu unggah ke repo (Add file → Upload files, pertahankan struktur folder). Setelah selesai, GitHub Pages akan diperbarui otomatis.
