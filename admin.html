PENYIMPANAN LANGSUNG (GITHUB)

Agar tombol simpan langsung mengubah repo dari browser, buat GitHub Personal Access Token (fine-grained): buka github.com → Settings → Developer settings → Fine-grained tokens → Generate. Beri akses Contents: Read and write hanya untuk repo bernaunginv. Token disimpan hanya di browser Anda (localStorage) dan tidak pernah dikirim ke tempat lain.

Tanpa token: panel tetap bisa dipakai — hasil perubahan/undangan akan diunduh sebagai file untuk Anda unggah manual ke GitHub (Add file → Upload files).

GANTI PIN ADMIN

PIN saat ini tersimpan sebagai hash di assets.bernaung.id/admin-auth.js. Dengan token terpasang, panel bisa menggantinya otomatis. Tanpa token, unduh file baru lalu unggah manual menggantikan file lama.

PANDUAN RSVP (SPREADSHEET + APPS SCRIPT)

1. Buat Spreadsheet baru di sheets.google.com → Extensions → Apps Script.
2. Hapus kode bawaan, tempel isi file assets.bernaung.id/Code.gs (tersedia juga di panel ini), Save.
3. Deploy → New deployment → Web app → Execute as: Me, Who has access: Anyone → Deploy → Allow.
4. Salin URL berakhiran /exec → tempel di form Customer Baru (bagian RSVP).
5. Selesai — RSVP undangan customer tersimpan otomatis ke spreadsheet Anda.

MODE MANUAL — UNGGAH FILE INI KE GITHUB

Token GitHub belum terpasang, jadi berikut file hasil proses. Klik unduh lalu unggah ke repo (Add file → Upload files, pertahankan struktur folder). Setelah selesai, GitHub Pages akan diperbarui otomatis.
